# 🧭 N-Body Problem

An interactive educational website exploring the mathematics behind multi-body gravitational systems, from the two-body problem to Hamiltonian mechanics for three bodies.

---

## 📖 Overview

This project presents a comprehensive mathematical treatment of the n-body problem—predicting the motion of celestial objects interacting gravitationally. We derive key concepts including reduced mass, center-of-mass transformations, Jacobi coordinates, and the Hamiltonian formulation, explaining why the problem has no general closed-form solution for n ≥ 3.

---

## 🧠 Topics Covered

- **Two-Body Problem**: Gravitational force derivation, reduced mass, and center-of-mass analysis
- **Hamiltonian Mechanics**: Energy formulation for the three-body system
- **Jacobi Coordinates**: Coordinate transformations that simplify the kinetic energy expression
- **Reduced Mass Formulations**: Decoupling techniques for multi-body systems
- **Complexity Analysis**: Why n ≥ 3 leads to coupled, nonlinear equations with chaotic behavior

## 📦 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/NPX2218/n-body-problem.git
cd n-body-problem
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

Then open your browser and visit: http://localhost:3000
